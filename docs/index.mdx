AI Chat is a production-oriented conversation workspace for teams that want to bring their own OpenAI-compatible model access. It combines persistent ChatGPT-style conversations, per-user credentials, remote MCP tools, local recovery accounts, runtime OIDC, and white-label branding in one Helm-deployed service.

## What it provides

- A serialized first-account administrator claim protected by an optional setup token.
- Database-backed local sessions and credentials with a permanent local recovery path.
- One runtime-configurable OIDC provider with controlled linking and optional just-in-time provisioning.
- Per-user OpenAI-compatible providers, API keys, endpoint headers, and model catalogs.
- Per-user remote MCP servers with tool fingerprinting and explicit re-trust after definition drift.
- Persistent, streaming Markdown conversations with reasoning and tool-call state.
- Runtime-configurable product name, tagline, logo, favicon, and accessible accent colors.
- A non-root, read-only Bun container and Helm chart with PostgreSQL 17 support.
