# AI Chat documentation

The documentation site uses [Mintlify](https://mintlify.com/).

From this directory:

```bash
mint dev
mint validate
mint broken-links --check-anchors --check-redirects
```

Install the CLI with:

```bash
npm install --global mint@4.2.795
```

Navigation and site settings live in `docs.json`. Add every public page to its navigation group so validation and readers can discover it.
